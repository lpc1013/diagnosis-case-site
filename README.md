# 诊断学临床思维训练 · 答案对照站

一个静态、零依赖的单页应用，用于对照「临床思维训练系统」整体思维训练 4 例病例的
标准答案与采集进度。支持答案模式（逐层「寻血」标记）、练习模式（百分制评分）、
移动端适配。

> 本项目为个人学习用途。校内系统的账号、密码与内网端点等凭据**不在此仓库中**，
> 相关爬虫与运维脚本亦已排除，请勿在公开场合分享。

## 目录结构

```
site/                    答案对照站前端（可独立部署）
  index.html             入口页（含缓存戳 ?v=N）
  serve.js               零依赖本地静态服务器（PORT 可配）
  assets/
    app.js               核心逻辑：渲染、答案标记、评分、localStorage 持久化
    style.css            样式（Stripe 风格浅色渐变、移动端适配）
  data/
    history_records.json 病例元信息（示例数据，展示数据结构）
                         （cases.json / diaglib.json 为大体量生成数据，见下）
docs/                    历次版本改进与自检记录（HTML）
```

> 注：`site/data/cases.json`（约 8MB，4 例完整数据）与 `site/data/diaglib.json`
> （约 1.5MB，诊断依据库）由私有爬虫脚本从源系统生成，体积过大且属于再生数据，
> 故**不纳入版本库**。如需本地运行完整站点，请用私有爬虫再生这两份文件后放入
> `site/data/`。

## 功能要点

- **答案模式**：正确选项及其所属一/二级结构逐层点亮（「寻血」标记），快速定位。
- **练习模式**：提交后按权重评分（病史 10% · 体格 10% · 辅助 70% · 诊断 10% · 治疗 0%），
  百分制展示各模块得分与总评。
- **进度对照**：各模块「已采集 / 总项」实时计数（如 病史 37/120）。
- **移动端**：响应式布局，悬浮球提交入口 + 说明提示；病例头在窄屏自动隐藏。
- **数据持久化**：`localStorage` 保存已选项、评分与标记，刷新不丢。

## 本地运行

```bash
cd site
node serve.js            # 默认 http://localhost:8787 ，可用 PORT 覆盖
```

## 部署

前端为纯静态文件，可部署到任意静态托管（CloudStudio / EdgeOne / GitHub Pages 等）。

| 模块 | 权重 |
|------|------|
| 病史 | 10% |
| 体格 | 10% |
| 辅助 | 70% |
| 诊断 | 10% |
| 治疗 | 0%（不计入满分门槛） |
